# Keymonk Modern DualSwipe Prototype

Version 0.1 is a clean-room Android IME prototype for testing on a Google Pixel 7.

It includes:
- Modern InputMethodService
- Custom QWERTY keyboard view
- Multi-touch two-finger swipe path tracking
- Debug candidate strip
- Tap-to-type basic letters
- Swipe commit format like `[qwe | iop]`

Build in Android Studio: open this folder, let Gradle sync, then Build > Build APK(s).
